Política de privacidade

A Mary Jane é usada apenas pela dona da conta Google que a autorizou.

  • O que acessa: Gmail (só leitura), Google Drive, Docs, Planilhas e Agenda dessa única conta.
  • Para quê: organizar e resumir o conteúdo para a própria dona.
  • Onde ficam os dados: no computador dela. Nada é vendido, compartilhado ou enviado a terceiros.
  • Outras pessoas: a Mary Jane não coleta dados de nenhum outro usuário.
  • Como revogar: em myaccount.google.com/permissions, removendo o acesso "Mary Jane".

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
